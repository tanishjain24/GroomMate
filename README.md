# GroomMate — Mosaic Challenge Prototype

A responsive, browser-based personal-care companion prototype.

## Run locally
1. Install Node.js (18+).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Build
Run `npm run build`. The deployable site is created in `dist/`.

## Deploy on Vercel (no backend required for this prototype)
1. Create a GitHub repository and upload this project.
2. Sign in to https://vercel.com/ and choose **Add New → Project**.
3. Import the repository.
4. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.
5. Click Deploy. Vercel will provide a public URL.

You can also deploy the `dist/` output to any static hosting provider.

## Prototype notes
- Routine checklist and journal entries are stored in the visitor's browser using localStorage.
- Product cards are generic illustrative examples, not verified Man Matters products.
- No customer names, phone numbers, health records, or customer interview data are included.
- This is an independent prototype, not an official Man Matters product or medical advice.
- Replace the generic catalogue and routine logic with brand-approved information only after validation.

## Suggested project explanation
GroomMate is a consumer-facing prototype designed to make personal-care routines easier to understand and maintain. It brings routine steps, a simple checklist, generic product-category discovery, and a personal journal into one browser experience. The prototype demonstrates how a brand could support customers beyond the point of purchase. Its final problem statement and product recommendations must be aligned with genuine customer interview findings before submission.
